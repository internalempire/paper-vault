# Paper Vault — interfaccia personale

Direzione vincolata dalla richiesta: strumento spartano per completare un lavoro, con controlli nativi e lettura comoda. Nessuna identità promozionale o illustrazione.

- Sistema: font di sistema del Mac, testo 16px/1.5, titoli 24px; monospace solo per il testo Markdown scaricabile.
- Superfici: pagina #f4f5f6, documento bianco, testo #20272b, secondario #566167, separatori #d5dadc.
- Accento: verde petrolio #176553 per azione primaria e passaggio attivo; stati positivi #176553, errore #9c302d.
- Geometria: contenitore 1160px, elenco lavori laterale 240px; nessuna griglia di card, pannelli separati da bordi semplici; pulsanti con raggio 6px.
- Navigazione: quattro passaggi numerati perché esprimono la sequenza reale. Un'azione primaria per stato.
- Fonte: input file nativo o URL. Testo completo in riquadro scorrevole con intestazioni e rimandi preservati.
- Revisione: figure intere, didascalia e passaggio della fonte; pulsanti Approva/Escludi. Anteprima nota sotto le figure.
- Responsive: sotto 760px lista lavori in details, contenuto a colonna; nessun contenuto perso. Controlli almeno 44px, focus visibile.
- Stati: estrazione, testo pronto, elaborazione, revisione, pubblicazione, pubblicato, errore/interrotto. Nessuna percentuale simulata. Tutti i dati provengono dalla pipeline.
- Movimento: transizione di colore sui controlli; nessuna animazione decorativa.
